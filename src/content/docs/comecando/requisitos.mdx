Antes de começar a usar o Criador de Produtos, confira se você tem tudo que precisa.

## Obrigatórios

### 1. WordPress

Você precisa ter o WordPress instalado e funcionando no seu servidor.

**Versão mínima**: 5.0 ou superior (recomendamos sempre a versão mais recente)

:::tip[Como saber minha versão?]
No painel do WordPress, vá em **Painel → Atualizações**. A versão atual aparece lá.
:::

### 2. WooCommerce

O WooCommerce deve estar instalado e ativo.

**Versão mínima**: 4.0 ou superior

**Como verificar**:
1. Vá em **Plugins → Plugins instalados**
2. Procure por "WooCommerce"
3. Deve estar com o link "Desativar" (significa que está ativo)

### 3. Plugin de Personalização

Você precisa de um plugin que permita adicionar campos personalizados aos produtos. O mais comum é:

- **WAPF** (WooCommerce Advanced Product Fields)
- Ou similar que use campos personalizados

:::note[Importante]
O Criador de Produtos foi desenvolvido para trabalhar com WAPF, mas pode funcionar com outros plugins similares. Teste antes!
:::

### 4. Pelo menos 1 produto configurado

Você precisa ter pelo menos uma bolsa (ou produto) já configurada com:
- Campos de personalização (nome, texto, etc.)
- Posições das gravações definidas
- Imagem do produto

Essa bolsa vai servir de **base** para criar ou atualizar outras.

## Recomendados

### Acesso Administrador

Você precisa estar logado como **Administrador** do WordPress para usar o plugin.

Outros perfis (Editor, Loja, etc.) não têm permissão para acessar a ferramenta.

### Navegador moderno

Use uma versão recente de:
- Google Chrome
- Firefox
- Safari
- Edge

:::caution[Internet Explorer não]
O plugin não funciona bem no Internet Explorer. Use um navegador moderno!
:::

### Conexão estável com a internet

Algumas operações podem demorar alguns segundos (principalmente ao atualizar muitas bolsas), então é bom ter uma conexão estável para não ser interrompido.

## Opcional mas útil

### Backup do site

Embora o plugin faça backups automáticos das configurações que ele muda, é sempre bom ter um backup completo do site antes de:
- Atualizar muitas bolsas de uma vez
- Fazer mudanças grandes

Use um plugin de backup como:
- UpdraftPlus
- BackWPup
- Ou o sistema de backup do seu provedor de hospedagem

### Conhecimento básico de WooCommerce

Não precisa ser expert, mas ajuda se você já sabe:
- Onde ficam os produtos
- Como editar um produto
- Como adicionar imagens de produtos
- Onde fica a biblioteca de mídia

## Checklist rápida

Antes de usar o plugin pela primeira vez, confira:

- [ ] WordPress instalado e atualizado
- [ ] WooCommerce ativo
- [ ] Plugin de personalização (WAPF) ativo
- [ ] Pelo menos 1 produto base configurado
- [ ] Logado como Administrador
- [ ] Navegador moderno
- [ ] Backup do site feito (recomendado)

## Problemas comuns

**"Não consigo ver o menu Criar Produto"**  
→ Você precisa ser Administrador. Peça para o administrador do site te dar acesso.

**"O plugin está instalado mas não funciona"**  
→ Verifique se o WooCommerce está ativo. O plugin precisa dele para funcionar.

**"Não tenho nenhum produto base"**  
→ Crie pelo menos um produto com campos de personalização primeiro. Depois volte para usar o plugin.
