## O que você pode fazer?

<CardGrid stagger>
  <Card title="✨ Criar Novos Produtos" icon="star">
    Crie uma bolsa nova copiando todas as opções de gravação de uma bolsa existente. Perfeito para criar variações de cores ou tamanhos.
  </Card>

  <Card title="🔄 Atualizar Várias Bolsas" icon="refresh">
    Atualize várias bolsas de uma só vez quando você mudar as opções de gravação do seu modelo base.
  </Card>

  <Card title="📐 Ajustar Posições" icon="setting">
    Mova as gravações para o lugar certo em cada bolsa sem precisar refazer tudo do zero.
  </Card>

  <Card title="👁️ Visualizar Antes" icon="preview">
    Veja como as gravações vão ficar posicionadas na bolsa antes de aplicar as mudanças.
  </Card>
</CardGrid>

Pequenos ajustes de alinhamento são necessários em todos os produtos após mudança no template de impressão.

**Solução**: Use o recurso de Ajuste Global para deslocar todos os elementos em X e/ou Y simultaneamente.

## Requisitos Técnicos

- WordPress 5.8 ou superior
- WooCommerce 6.0 ou superior
- PHP 7.4 ou superior
- Plugin de personalização compatível (ex: WAPF)
