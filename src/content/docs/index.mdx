## Como Funciona

O WC Product Creator foi desenvolvido para trabalhar com produtos WooCommerce que utilizam plugins de personalização (como WAPF - WooCommerce Advanced Product Fields). O fluxo de trabalho é simples e direto:

1. **Selecione o Produto Base**: Escolha um produto existente que servirá como modelo
2. **Escolha os Campos**: Selecione quais campos e posicionamentos deseja copiar
3. **Ajuste as Posições**: Use o editor visual para modificar coordenadas X e Y
4. **Visualize**: Confira o preview antes de aplicar
5. **Execute**: Crie novos produtos ou atualize produtos existentes em lote

## Casos de Uso

### Linhas de Produtos Personalizáveis

Você tem uma linha de camisetas personalizáveis e precisa criar variações para diferentes cores de tecido, mantendo as mesmas áreas de personalização (nome, número, logo).

**Solução**: Use um produto base como template e crie rapidamente todas as variações, ajustando apenas as posições conforme necessário para cada cor de fundo.

### Atualização de Layout

Após um redesign das áreas de impressão, você precisa atualizar o posicionamento dos campos em dezenas de produtos.

**Solução**: Configure as novas posições em um produto base e aplique as mudanças em massa para todos os produtos da categoria.

### Ajustes Finos de Posição

Pequenos ajustes de alinhamento são necessários em todos os produtos após mudança no template de impressão.

**Solução**: Use o recurso de Ajuste Global para deslocar todos os elementos em X e/ou Y simultaneamente.

## Requisitos Técnicos

- WordPress 5.8 ou superior
- WooCommerce 6.0 ou superior
- PHP 7.4 ou superior
- Plugin de personalização compatível (ex: WAPF)
